Work offline

Take the tools with you

Every tool is also provided as one self-contained HTML file. It needs no installation, server, account, or internet connection.

  1. Select Download standalone HTML on a tool card.
  2. Save the file somewhere convenient on your computer.
  3. Double-click the saved file to open it in your usual web browser.

If your browser opens the HTML instead of saving it, right-click the download button and choose Save link as.

Beta testing and feedback

Help us make the toolkit better

This toolkit is currently in beta testing. There may be mistakes, missing hubs, or requirements that have changed. Always compare generated files with your selected hub’s current instructions and official validation process before submission.

We are always looking for feedback. If something is unclear or you find a possible error, please let us know.
