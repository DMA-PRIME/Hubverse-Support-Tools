Work offline

Take the tools with you

Every tool is also provided as one self-contained, clearly labeled offline HTML file. It needs no installation, server, account, or internet connection for its core features. Opening official Hubverse or GitHub links still requires internet access.

  1. Select Download standalone HTML on a tool card.
  2. Save the file somewhere convenient on your computer.
  3. Double-click the saved file to open it in your usual web browser.

If your browser opens the HTML instead of saving it, right-click the download button and choose Save link as.

Update note: Standalone downloads include metadata-schema and hub-configuration snapshots. If a hub changes its rules, re-download the appropriate tool for the newest bundled version or upload the hub’s current JSON files manually.
