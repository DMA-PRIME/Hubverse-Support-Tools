HUBVERSE SUPPORT TOOLKIT — OFFLINE TOOLS

Each HTML file in this folder is a self-contained browser application.

Included tools:
- Hubverse-Metadata-Generator.html
- Hubverse-Data-Preparation.html
- Hubverse-Submission-Guide.html

To run a tool offline:
1. Save the HTML file on your computer.
2. Double-click the file.
3. If asked, choose a modern browser such as Chrome, Edge, Firefox, or Safari.

No installation, account, local server, or internet connection is required for
the core tool. Links to external documentation require internet access.

These tools are in beta testing. Always compare generated files with your hub's
current instructions and official validation process before submission.
The Submission Guide is being actively validated, and its screenshots are being
updated. Confirm its instructions against the selected hub before submitting.
